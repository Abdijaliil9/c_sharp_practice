# Chapter 3: Making Decisions — Important Concepts

> This README covers the key concepts of Chapter 3. Code examples are intentionally excluded.

## 1. Decision Structures

* A decision structure controls the flow of program execution based on conditions.
* It allows a program to choose which statements to execute.
* A condition produces a Boolean result: `true` or `false`.
* A sequence structure executes statements in order, while a decision structure selects actions based on conditions.

## 2. Conditional Statements

* **If Statement:** Executes a block of statements when a condition is true.
* **If-Else Statement:** Provides two alternative execution paths depending on whether a condition is true or false.
* **Nested If Statement:** Places one decision structure inside another.
* **If-Else-If Statement:** Evaluates multiple conditions to determine the appropriate action.

## 3. Relational Operators

Relational operators compare two values and return a Boolean result.

* **Greater Than (`>`):** Checks whether one value is greater than another.
* **Less Than (`<`):** Checks whether one value is less than another.
* **Greater Than or Equal To (`>=`):** Checks whether one value is greater than or equal to another.
* **Less Than or Equal To (`<=`):** Checks whether one value is less than or equal to another.
* **Equal To (`==`):** Checks whether two values are equal.
* **Not Equal To (`!=`):** Checks whether two values are different.

## 4. Logical Operators

Logical operators combine or reverse Boolean conditions.

* **AND (`&&`):** Returns true when both conditions are true.
* **OR (`||`):** Returns true when at least one condition is true.
* **NOT (`!`):** Reverses a Boolean value.

## 5. Boolean Variables and Flags

* A Boolean variable stores one of two possible values: `true` or `false`.
* A flag is a Boolean variable used to indicate whether a particular condition or state exists.
* Flags help control program execution and track specific program states.

## 6. String Comparison

* String comparison determines whether two text values are equal or different.
* C# provides comparison operators and the `String.Compare()` method for comparing strings.
* String comparison allows programs to make decisions based on text input.
* The comparison method used may affect whether uppercase and lowercase letters are treated as different.

# C# Math Expressions, Type Conversion, and Exception Handling

## Introduction

This project demonstrates some basic and important concepts in C# programming, including mathematical expressions, variables, data types, type conversion, integer division, user input, output, and exception handling. The program uses C# Windows Forms controls such as TextBoxes, Labels, and MessageBoxes to receive input, perform calculations, display results, and handle errors.
